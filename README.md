# Project-Based Learning PBL Codes

This repository contains a collection of project-based learning (PBL) codes for various Adafruit libraries and devices. These projects demonstrate how to use Adafruit hardware and libraries to build interactive and functional systems.

## Overview
This repository includes examples and libraries for:
- Adafruit MPU6050 (6-DoF Accelerometer and Gyro)
- Adafruit SSD1306 (Monochrome OLED displays)
- Adafruit GFX Library (Graphics primitives)
- Adafruit BusIO (I2C, SPI, and UART abstraction)

These examples are designed to help you get started with Adafruit hardware and libraries.

## Features
- Accelerometer and gyroscope data collection using MPU6050.
- Display graphics and text on OLED screens using SSD1306.
- Unified sensor abstraction for easy integration.
- SPI and I2C communication examples.
